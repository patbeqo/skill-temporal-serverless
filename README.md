# Temporal Serverless Workers Skill

A skill for coding agents to use when deploying and operating [Temporal](https://temporal.io/) Workers on serverless compute (AWS Lambda).

> [!WARNING]
> This Skill is currently in Public Preview, and will continue to evolve and improve.
> We would love to hear your feedback - positive or negative - over in the [Community Slack](https://t.mp/slack), in the [#topic-ai channel](https://temporalio.slack.com/archives/C0818FQPYKY)

> [!NOTE]
> Serverless Workers are in Pre-release and available to select Temporal Cloud customers.

## Installation

1. `mkdir -p ~/.claude/skills && git clone https://github.com/temporalio/skill-temporal-serverless ~/.claude/skills/temporal-serverless`

Appropriately adjust the installation directory based on your coding agent.

## Currently Supported Temporal SDK Languages

- [x] Go
- [x] Python
- [x] TypeScript
